# claude1 — Paper Generation Workspace (Phase 1: Cross-Family)

Huddle assignment: **Phase 1 — Cross-family SLM comparison** (Qwen / Gemma / Llama / GLM @ ~8B, Q4_K_M; DeepSeek excluded from Phase 1).

## Contents
- `plots/gen_figures.py` — derives all Phase-1 statistics from raw results and renders 6 figures.
- `plots/build_docx.py` — builds `claude1_paper.docx`, styled after `paper/paper_comprehensive_v3.docx`, embedding the figures.
- `plots/phase1_stats.json` — machine-generated derived numbers (regenerated by `gen_figures.py`).
- `figures/fig1..fig6.png` — publication figures.
- `claude1_paper.docx` — final paper section (Section 4).

## Reproduce
```bash
cd <repo root>
python3 paper/claude1/plots/gen_figures.py   # -> figures/ + phase1_stats.json
python3 paper/claude1/plots/build_docx.py     # -> claude1_paper.docx
```

## Data sources (verified)
- `results/phase1/benchmark_*.json` (4 ranked families; DeepSeek file ignored) and `results/complete_benchmark.json` — Phase-1 raw, 200 intents/model.
- `results/ci_summary_v3.json` — Qwen size×quant CIs; used **only** for the §4.5 scaling bridge (contains no cross-family rows).
